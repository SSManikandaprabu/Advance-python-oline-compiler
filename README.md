# PyAdvance - Advanced Python Online Compiler

A feature-rich in-browser Python coding workspace and online compiler with theme controls, code formatting, and code snippets.

## Features

- In-browser Python code execution sandbox
- Syntax-highlighted code editor with line numbering and tab formatting
- Pre-built starter templates and algorithm snippets
- Standard input (stdin) simulation for interactive script execution
- Dedicated execution terminal displaying standard output and runtime exceptions
- **Code action toolbar**: Code action toolbar: Run, Format, Copy Code, Save File, and Clear Editor
- Visual customizer with multiple developer themes and font size controls
- Local storage caching to keep your code intact across browser reloads

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Font Awesome
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Advance-python-oline-compiler.git
   cd Advance-python-oline-compiler
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `advanced_python_online_compiler.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/advanced_python_online_compiler.html](http://localhost:8000/advanced_python_online_compiler.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for PyAdvance - Advanced Python Online Compiler.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
